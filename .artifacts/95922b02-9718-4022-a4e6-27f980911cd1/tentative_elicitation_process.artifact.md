# AquaWatch: Elicitation Process

## 1. Stakeholder Profiling
*   Categorize users: Contributors, Verifiers, and Analysts.
*   Identify motivations and pain points for each group.

## 2. Gathering Methods
*   **Interviews**: One-on-one with officials for verification needs.
*   **Surveys**: Wide-reaching data on community concerns.
*   **Workshops**: Collaborative co-creation of the report workflow.

## 3. Scoping & Prototyping
*   **Research Focus**: Define data types and accuracy targets.
*   **UI/UX Testing**: Use low-fi mockups for early usability checks.
*   **Pilot Phase**: Small-scale field test to find friction points.

## 4. Finalization
*   Translate findings into formal technical requirements.
*   Obtain stakeholder sign-off on the project scope.
